# TP3 - Sistema de inventario

Proyecto Maven (Java 17). Ejecutar `TP3.Menu`.

- Los datos se guardan en `Inventario.dat` (texto plano, campos separados por `;`):
  `nombre;precioCompra;precioVenta;stock`, por ejemplo `manzana;50.6;100.7;240`.
  Si el archivo no existe, el programa lo crea.
- Los colores usan códigos ANSI: ejecutar desde cmd / PowerShell / Windows Terminal
  (en la consola de Eclipse hace falta el plugin "ANSI Escape in Console").
