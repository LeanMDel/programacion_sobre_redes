# TP2 - Manejo de archivos en Java

Proyecto Maven (Java 17). Ejecutar `TP_2.main` para el menú con los 9 ejercicios,
o cualquier clase por separado (todas tienen su propio `main`).

| # | Clase | Archivo que genera |
|---|-------|--------------------|
| 1 | GuardarUltimoDato | `ultimoDato.txt` (carpeta del proyecto) |
| 2 | GuardarValoresNumeros | `GuardarValoresNumeros.txt` (carpeta del proyecto) |
| 3 | GuardarNumerosPares | `~/TP2_Numeros/números.txt` |
| 4 | LeerNumeros | lee `números.txt` |
| 5 | BorrarNumerosMulti3 | modifica `números.txt` |
| 6 | Numeros_Primos | `~/TP2_Primos/primos.dat` |
| 7 | ArchivoCaracteres | `~/TP2_Caracteres/caracteres.dat` |
| 8 | BorrarLorem | modifica `lorem.html` (carpeta del proyecto) |
| 9 | MenuClima | `clima.txt` (carpeta del proyecto) |

Orden recomendado para 3 a 6: 3, 4, 5, 6.
Para terminar de cargar datos en cualquier ejercicio: escribir `fin`.
Antes de probar el 8, guardar una copia de `lorem.html` (el ejercicio borra el lorem del archivo).
